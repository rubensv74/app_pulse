# Active PULSE Flow Definitions

This directory contains real exported/deployable definitions for **currently active** Power Automate flows.

Do not create placeholder or inferred flow definitions here.

For each flow captured from the environment, record enough metadata to identify its runtime authority, including the flow display name, export/source date, relevant caller(s), and validation status.

Missing definitions are treated as coverage gaps, not as permission to reconstruct internals from memory or from Power Apps call signatures.
