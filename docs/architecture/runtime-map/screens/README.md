# Pantallas

Cada pantalla tendrá una ficha `<screen-name>.md` cuando el inventario completo sea generado.

Contenido mínimo:

- propósito funcional;
- eventos analizados;
- flows invocados;
- variables y colecciones relevantes;
- navegación entrante y saliente;
- baseline y evidencia;
- estado de cobertura.

La primera cobertura parcial está resumida en `../mappings/screen-to-flow.md`.
