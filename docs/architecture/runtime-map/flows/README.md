# Flows de Power Automate

Cada flow tendrá una ficha `<flow-name>.md` con:

- propósito;
- trigger y parámetros;
- respuesta a Power Apps;
- procedimientos o conectores consumidos;
- lecturas y efectos;
- pantallas consumidoras;
- estado: `ACTIVE_OBSERVED`, `UNREFERENCED_CANDIDATE` o `REVIEWED_KEEP/REMOVE`;
- baseline y evidencia.

`UNREFERENCED_CANDIDATE` no autoriza la eliminación. Solo crea una cola de revisión.
