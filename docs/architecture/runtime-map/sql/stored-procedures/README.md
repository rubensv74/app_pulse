# Procedimientos almacenados

Las fichas de procedimiento describirán:

- propósito;
- parámetros y salida;
- tablas leídas y modificadas;
- flows consumidores;
- códigos de resultado;
- paginación y orden;
- efectos, transacciones y riesgos;
- evidencia del catálogo SQL.

La definición completa seguirá viviendo en `sql/` o en el catálogo del esquema.
