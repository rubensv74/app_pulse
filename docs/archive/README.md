# PULSE Archive

This area preserves historical evidence that must remain available for traceability but is **not** a current source of truth.

## Rules

- archived files must not be used to infer current runtime behavior when canonical source exists;
- historical delivery manifests and reports belong under `deliveries/`;
- superseded standards/guides belong under `superseded-docs/` when they no longer need a compatibility stub at the old path;
- sprint-specific evidence belongs under `sprints/` when it no longer represents an active development workspace;
- archive moves must preserve enough metadata to identify the original path/date/context.

Canonical current documentation starts at `../README.md`.
